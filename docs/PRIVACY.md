# Privacy Policy

Jagex Switcher does not collect, transmit, sell, or share personal data.

The app stores profile metadata and encrypted RuneLite/Jagex session values locally on the user's Windows account under `%APPDATA%\jagex-account-switcher\`. Credential files are encrypted with Windows DPAPI for the current Windows user.

Pair Transfer is optional. When used, the sending copy of the app serves one selected encrypted session through a temporary Cloudflare Tunnel URL plus an 8-digit pairing code. The share closes after one import, five failed code attempts, 15 minutes, Stop Share, or app exit.

Jagex Switcher does not operate a backend service or analytics system.
